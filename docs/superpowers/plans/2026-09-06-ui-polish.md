# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the approved polish pass from `docs/superpowers/specs/2026-09-06-ui-polish-design.md`: the unified toolbar (direction C), the reader header and thread collapsing, and the Codex pane, as three PRs.

**Architecture:** All work is in `services/web` (presentation only). `src/main.ts` owns the DOM template string, element lookup, state, and event wiring; `src/styles.css` owns layout. Each task rewrites one region of the template, updates the handlers that touch it, adjusts CSS, and updates the Playwright specs that select the old markup. No service, contract, or command changes.

**Tech Stack:** TypeScript, Vite, Tabler 1.4 CSS + Tabler icons webfont, Playwright (`npx playwright test`), Vitest (`npm test`). Branch per task from `origin/main`; open PRs with `scripts/ci-sandbox.sh open-pr <branch>`.

## Global Constraints

- Tabler tokens only: primary `#066fd1`, borders `var(--tblr-border-color)`, radii `var(--tblr-border-radius)` (6px), font Inter via Tabler.
- Nothing in the window prints "Dispatch". No status bar on desktop.
- `data-tauri-drag-region` stays on the toolbar; native shell keeps `padding-left: 84px` for the traffic lights (`.dispatch-native`).

  const article = document.createElement('article')
  article.className = 'card dispatch-thread-message'

  if (message.attachments.length > 0) {
